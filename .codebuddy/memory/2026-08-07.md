## B扫C 支付架构实现

实现了完整的 B 扫 C（商家扫用户付款码）支付架构，模拟真实微信/支付宝支付流程。

### 新增文件
- `migrations/0002_payments.sql` — 支付记录表 + 订单支付追踪字段
- `src/app/api/payment/micropay/route.ts` — B扫C 微支付接口（230行）
- `src/lib/services/checkout.ts` — 订单结算共享服务（270行），从原始 check 路由提取

### 修改文件
- `src/app/api/cashier/checkout/route.ts` — 重构使用共享 checkout 服务
- `src/app/(main)/cashier/page.tsx` — 新增支付方式选择 → 扫码 → micropay API 完整流程

### 支付流程
1. 选择商品 → 去结算 → 选择支付方式（现金/手机）
2. 现金: 直接调用 checkout API
3. 手机: 打开扫码器 → 扫描付款码 → 调用 micropay API
   - 服务端验证 auth_code 格式 → 自动识别微信/支付宝 → 模拟支付平台 → 成功则创建订单
4. 支付成功 → 清空购物车 → 显示成功弹窗 → 可打印票据
5. 支付失败 → 显示错误 → 返回支付方式选择可重试

## QRScanner 修复
- **Cannot stop 错误**: 用 `isRunningRef` 替代 `stoppedRef`，只有 `scanner.start()` resolve 后才标记运行中，关闭时仅在运行中才调 `stop()`
- **双重视频**: Strict Mode 下组件双重挂载导致两个 `<video>` 叠加，在 useEffect 开头、cleanup、handleClose、扫码成功回调 4 处加 `container.innerHTML = ''` 清理

## 支付安全性修复

- 扫码成功回调补了 `setShowCheckout(false)` 防止结算弹窗残留显示价格为 0

## 收银台扫码枪扫描商品

实现了扫码枪（键盘楔模式）扫描商品条码直接加入购物车的功能。

### 新增文件
- `src/app/api/cashier/products/scan/route.ts` — 条码查商品 API
  - `GET /api/cashier/products/scan?code=xxx`
  - 找到已上架商品 → 200 + 商品信息
  - 不存在 → 404
  - 已下架 → 400

### 修改文件
- `src/app/(main)/cashier/page.tsx`:
  - 新增 `Barcode` 图标、`useRef` import
  - 新增 scan 状态：`scanCode`, `scanStatus`, `scanFeedback`, `scanning`, `scanInputRef`
  - 新增 `isModalOpen` 计算 — 弹窗打开时屏蔽扫码防误触发
  - `useEffect` 自动聚焦扫码输入框（弹窗关闭后自动恢复）
  - `handleScanProduct` — 扫码 + 加入购物车（已存在则+1，上限99）
  - `scrollToProduct` — 扫码后滚动商品卡片到可视区域
  - 工具栏新增扫码枪输入框：Barcode 脉冲图标 + 输入框 + 状态反馈文字
  - 商品卡片加 `id="product-card-{id}"` 支持滚动定位

### 交互细节
- 输入框始终自动聚焦（弹窗打开时自动失焦/禁用）
- 成功：边框变绿 + 反馈文字 "商品名 xN"
- 失败：边框变红 + 反馈文字（未找到/已下架）
- 反馈 2.5s 后自动消失
- 重复扫码同一商品自动累加数量
- 所有 modals（结算/支付/扫码/成功/打印预览）打开时完全屏蔽
